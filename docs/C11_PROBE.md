# C11 能力探测 APK

这是无线 CarPlay 计划 M0 的首个工具，包名 `com.shihab.diplay.c11probe`。它是独立 Android 应用，不依赖 CarPlay 认证文件，不启动 BYD 服务，不连接车辆控制总线，也不建立 CarPlay 会话。可与 DiPlay 同时安装。

## 构建

沿用仓库的 JDK 25、Gradle wrapper 和 Android SDK 37.0；此模块不需要 NDK。首次构建需下载依赖。

```sh
./gradlew :probe:testDebugUnitTest :probe:lintDebug :probe:assembleDebug --configure-on-demand
```

输出：`probe/build/outputs/apk/debug/probe-debug.apk`。普通 debug 签名仅用于能力验证。升级探测包应使用同一签名；本工具没有身份资产输入，也不应配置 `DIPLAY_AUTH_ASSETS_DIR`。

## 实车使用

1. 停车，通过车机允许的 APK 安装渠道安装并打开“DiPlay C11 能力探测”。填入手机上的高德版本，可留空。
2. 点击“授权蓝牙与通知”，再刷新报告。未授权会单独标为 `permission_denied`，不会阻止其他能力采集。无需定位、麦克风、VPN、Usage Access 或 root。
3. 点击“开始方向盘测试”。它播放每两秒一次的轻声测试音并申请临时媒体焦点，原厂音乐可能暂停。分别测试上一首、下一首、播放暂停，随后返回原厂桌面再测试；60 秒自动停止，也可用应用按钮或通知立即停止。音量不由应用截获。测试期间不要同时操作高德版本输入框来判断方向盘分发。
4. 重新打开应用查看事件。`activity_key` 仅表示前台窗口收到了键；`media_key` / `media_command` 表示媒体会话收到了按键或控制回调。两条观察路径可能记录同一次物理操作，不表示向 iPhone 重复发了命令，本工具完全不发送 iPhone 指令。测试记录最近 200 条，进程退出后不持久保存。
5. 显示测试只列出公共、有效、非当前屏且带 Presentation 标记的显示。先从原厂导航模式确认哪一个是仪表导航区域。**用途不明确就取消，不要逐个屏幕试。** 确认后仅显示一个小窗口，10 秒后或离开探测页面即关闭；随后记录仪表上是否确实可见。
6. 停止测试，刷新报告并导出 JSON。Android 10+ 保存到 `Download/DiPlay`；Android 9 使用系统文件选择器。车机不支持文件导出时可复制报告。导出的文件在卸载后仍需自行删除。

## 如何解释结果

| 结果 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| 蓝牙 enabled / pairedDeviceCount | 应用有权读取蓝牙状态及配对数量 | iPhone 可建立 RFCOMM、认证可用 |
| 5 GHz station capability | 系统声明支持 5 GHz 客户端 | 热点/P2P 支持 5 GHz，或实际链路稳定 |
| 网络地址数量 | 存在相应地址族接口 | 哪个接口是热点、mDNS 或手机可达 |
| H.264 declares720p30 | 解码器声明支持这个格式 | 实际成功解码；尚未送入视频码流 |
| presentationCandidate | 应用看到可尝试的公共显示 | 它属于仪表、窗口有权限或物理上可见 |
| window_accepted | `Presentation.show()` 未抛出异常 | 仪表实际呈现；需另看车主观察记录 |
| owner_reported_visible | 车主确认本次测试图在导航区域可见 | 高德独立地图流存在、后台/异常清理已全部验证 |
| 没有媒体键事件 | 本次观察未收到支持范围内的键 | 方向盘完全不支持；需排查焦点、系统分发及私有键 |

应用只观察标准媒体、音量、电话、语音和方向键，不记录字母/数字输入，也不读取所有系统输入。语音/电话键出现在前台日志不等于已经接入 Siri 或通话。

报告不导出蓝牙设备名/MAC、网络接口名称/IP、热点 SSID/密码、显示名称/唯一标识或配对记录。保留设备型号、系统版本和经常见标识过滤的固件指纹，用于确定适配边界。它不读取其他应用的日志或数据；报告无自动上传。复制操作会将报告放入车机剪贴板，使用后可清除。

## 已实现与仍需验证

- 已实现：独立入口、按权限降级的能力快照、可停止的媒体会话测试、候选显示限制与临时小窗口、事件记录、JSON 导出和复制。
- 本机自动测试覆盖：敏感字段过滤、事件容量、显示候选排除、蓝牙权限拒绝、主屏报告、音频焦点拒绝以及无认证启动。
- 尚需实车：媒体键分发、真实扬声器音量、仪表窗口可见性、后台和休眠表现。
- 无线认证、真实 H.264 解码和高德独立第二流属于后续 M1；不要把该探测包当作 CarPlay 接收器。
